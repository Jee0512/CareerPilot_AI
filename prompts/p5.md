# 5. CURRENT TECHNOLOGY DECISIONS
============================================================

## Streamlit

KEEP.

Use a modern supported Streamlit version appropriate for:

- st.navigation
- st.Page
- st.switch_page
- st.page_link
- st.html
- current component APIs

Do not downgrade to an old Streamlit version.

Before changing requirements.txt, inspect the actual installed environment.

If the repository has a tested version, preserve compatibility unless migration requires an upgrade.

------------------------------------------------------------

## Routing

USE:

st.navigation
st.Page
st.switch_page
st.page_link

The old custom:

st.session_state["page"]

routing mechanism should be removed where it has been replaced.

------------------------------------------------------------

## State

USE:

st.session_state

Do not introduce:

- Redux
- Zustand
- React global state
- database
- custom state server

Authoritative application state remains in Python/Streamlit.

------------------------------------------------------------

## Native widgets

KEEP native Streamlit widgets for:

- buttons
- inputs
- text areas
- uploads
- forms
- tabs
- downloads
- radios
- selects
- checkboxes
- progress
- loading states

Do not recreate these in HTML.

------------------------------------------------------------

## Static custom UI

USE:

st.html()

for presentation-only UI where native Streamlit cannot provide the desired visual structure.

Examples:

- score cards
- badges
- static comparison
- visual metrics
- decorative layouts
- static skill displays

------------------------------------------------------------

## Components v2

DO NOT build Components v2 yet unless the actual current CareerPilot requirements prove that a component cannot be implemented cleanly with:

Native Streamlit
or
st.html()

However, the architecture MUST remain capable of introducing Components v2 later.

------------------------------------------------------------

## React

Do not introduce React at the application level.

React may be introduced later only inside a justified Component v2.

------------------------------------------------------------

## Tailwind

REMOVE the current Tailwind CDN architecture.

Do not install global Tailwind.

Do not add:

cdn.tailwindcss.com

Do not introduce Node/Vite merely for the current Streamlit design system.

Tailwind may be used later inside a justified frontend Component v2.
