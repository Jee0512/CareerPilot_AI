==================================================

must be evaluated.

Do not automatically replace it with st.metric().

Original Score
        ↓
Optimized Score
        ↓
Improvement

The visual hierarchy should remain strong.

If a reusable component is justified, add:

    render_score_comparison(...)

to:

    ui/components.py

It must:

- use .cp-ui
- use existing tokens
- use semantic markup
- accept semantic values
- contain no business logic
- use st.html()
- remain reusable
