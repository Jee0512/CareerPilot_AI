# 3. REACT / COMPONENTS V2 DECISION
# ================================================================

CURRENT DECISION:

React is NOT part of the architecture.

Streamlit Components V2 is NOT part of the architecture.

Do NOT introduce either simply to make the application look more premium.

Use the following escalation ladder:

1. Native Streamlit widget/API
2. Native Streamlit layout primitive
3. st.html() for static presentation
4. Existing ui/components.py abstraction
5. New reusable presentation component
6. Components V2 ONLY if a concrete requirement cannot reasonably be satisfied above
7. React ONLY if Components V2 / native architecture genuinely requires a frontend application

If a phase reaches level 6 or 7:

STOP.

Do not implement it.

Report:

- requirement
- why native Streamlit fails
- why st.html() fails
- why existing components fail
- why Components V2 would be required
- why React would be required
- alternatives considered

Wait for human approval.
